# Leader for Trans — الشجرة المحاسبية
## نظام ليدر

---

**الإصدار:** 1.0  
**التاريخ:** يوليو 2026  
**المرجع:** بناءً على الهيكل المحاسبي الفعلي المطبّق في النظام

---

## مقدمة

نظام **Leader for Trans** يعتمد على **محاسبة تشغيلية متكاملة** مرتبطة مباشرة بعمليات النقل واللوجستيات. لا يستخدم النظام جدولاً تقليدياً لشجرة حسابات عامة (General Ledger)، بل يُدار كل حساب عبر **وحدات مالية مترابطة** تُحدّث أرصدتها تلقائياً مع كل عملية.

هذا المستند يعرّف **الشجرة المحاسبية الوظيفية** للنظام — أي تصنيف كل حساب، طبيعته (مدين/دائن)، مصدره في النظام، والحركات التي تؤثر عليه.

## 1. الأصول (Assets)

### 11 — الأصول النقدية والبنكية

| الكود | اسم الحساب | الوصف | مصدر في النظام | طبيعة الحساب |
|-------|-----------|--------|----------------|--------------|
| **1101** | **الخزنة الرئيسية (Vault)** | النقد المركزي للشركة | جدول `vaults` — رصيد واحد رئيسي | مدين |
| **1102** | **حسابات البنوك** | حسابات بنكية متعددة | جدول `banks` — حساب فرعي لكل بنك | مدين |
| **1103** | **شيكات تحت التحصيل** | شيكات مسجّلة ولم تُستحق بعد | `invoice_payments` حيث `payment_type = check` و `check_paid_at = null` | مدين |

#### حركات حساب 1101 — الخزنة

| الحركة | التأثير | المصدر |
|--------|---------|--------|
| صرف عهدة للمندوب | **−** (خصم) | `MoneyTransfer` نوع 1 + `VaultTransaction` نوع 0 |
| سحب من البنك للخزنة | **+** (إضافة) | `BankTrnsaction` نوع 0 |
| سداد سيارات (ناقلين) | **−** (خصم) | `Payingcar` + `AccountController::processCarPayment` |
| دفع خدمات حجز من الخزنة | **−** (خصم) | `BookingService` حيث `payment_type = vault` |

#### حركات حساب 1102 — البنوك

| الحركة | التأثير | المصدر |
|--------|---------|--------|
| إيداع (سداد عميل) | **+** | `BankTrnsaction` نوع 1 — سداد فواتير أو رصيد افتتاحي |
| سحب (تحويل للخزنة) | **−** | `BankTrnsaction` نوع 0 |
| تحويل بين بنكين | **−/+** | `BankTrnsaction` نوع 2 |
| استحقاق شيك | **+** | عند الضغط «تم الاستحقاق» في صفحة الشيكات |

> **ملاحظة:** رصيد البنك = مجموع الإيداعات (type=1) − مجموع السحوبات (type=0)

### 12 — الذمم المدينة (العملاء)

| الكود | اسم الحساب | الوصف | مصدر في النظام | طبيعة الحساب |
|-------|-----------|--------|----------------|--------------|
| **1201** | **ذمم مدينة — عملاء** | المبالغ المستحقة على الشركات (العملاء) | كشف حساب الشركة (`accounts.statement`) | مدين |
| **1202** | **رصيد افتتاحي مدين** | مديونية سابقة على العميل قبل النظام | `companies.opening_balance` (قيمة موجبة) | مدين |

#### معادلة حساب 1201 — ذمم العملاء

```
الرصيد المستحق = (مجموع الفواتير + الرصيد الافتتاحي + الرصيد المرحّل)
                 − (مجموع المدفوعات المؤكدة)
```

| الحركة | التأثير | المصدر |
|--------|---------|--------|
| إصدار فاتورة حجز | **+** (زيادة المديونية) | `invoices` المرتبطة بـ `bookings` |
| سداد تحويل بنكي | **−** | `invoice_payments` نوع `bank_transfer` |
| سداد شيك (بعد الاستحقاق) | **−** | `invoice_payments` نوع `check` + `check_paid_at` |
| سداد الرصيد الافتتاحي | **−** | خصم من `companies.opening_balance` |

#### مكونات الفاتورة (1201)

| البند | الحقل في النظام |
|-------|----------------|
| إيراد النقل | `transportation_total_before_vat` |
| خدمات ضريبية | `taxed_services_total_before_vat` |
| خدمات غير ضريبية | `untaxed_services_total_before_vat` |
| ضريبة القيمة المضافة | `value_added_tax` (نسبة) |
| ضريبة المبيعات | `sales_tax` (نسبة) |
| خصم | `discount` (قيمة ثابتة) |

> **رقم الفاتورة:** `YYYY-XXX-###` (سنة — رقم الشركة — تسلسل)

## 11. دورة محاسبية متكاملة (مثال)

```
[1] العميل يطلب حجز
    → لا تأثير محاسبي (حتى إصدار الفاتورة)

[2] إصدار فاتورة
    مدين: 1201 ذمم العملاء
    دائن: 4101 إيراد النقل + 4102/4103 خدمات + 2201 VAT

[3] سداد العميل (تحويل بنكي)
    مدين: 1102 البنك
    دائن: 1201 ذمم العملاء

[4] صرف عهدة للمندوب
    مدين: 1301 عهدة المندوب
    دائن: 1101 الخزنة

[5] المندوب ينفّذ نقلة (بوليصة تسليم)
    مدين: 5303 عهدة نقلات / 5103 مصروفات
    دائن: 1301 عهدة المندوب

[6] تسوية النقلة + عمولة المكتب
    دائن: 4104 عمولة المكتب
    تسوية: 2101 ذمم السيارات

[7] سداد السيارة
    مدين: 5302 سداد سيارات
    دائن: 1101 الخزنة
    (يُخفض 2101)
```

## 13. ملاحظات مهمة

1. **لا يوجد دفتر يومية عام (General Journal)** — كل حركة تُسجّل في الوحدة المختصة (بنك، خزنة، عهدة، فاتورة).
2. **الشيكات** لا تُضاف للبنك إلا بعد تأكيد «تم الاستحقاق» من صفحة إدارة الشيكات.
3. **تقرير الأرباح والخسائر** يحسب: إجمالي الفاتورة − (مصروفات المندوب + التكاليف الإضافية على الحاويات).
4. **العملة:** جنيه مصري (EGP) في كل الحسابات.
5. **الفواتير الإلكترونية:** تُدار عبر `CompanyFatoorah` + API مصلحة الضرائب (ETA).
