1. نظرة عامة

Leader for Trans (نظام ليدر) هو منصة متكاملة لإدارة عمليات نقل وتحريك الحاويات وخدمات الشحن البري واللوجستيات، مصممة خصيصاً لشركات النقل في السوق المصري.

يربط النظام بين المكتب الإداري، فريق العمل الميداني، والعملاء (الشركات) في منصة واحدة تغطي دورة العمل الكاملة من تسجيل الحجز حتى الفوترة الضريبية وتحصيل المدفوعات والتقارير المالية.

2. فكرة التطبيق والمشكلة التي يحلها

شركات نقل الحاويات تعتمد على عمليات متعددة ومتداخلة: حجوزات من عملاء مختلفين، حاويات متعددة لكل حجز، مندوبين ميدانيين ومشرفين، سيارات وسائقين، مصاريف يومية وعهدة مالية، فواتير ضريبية ومتابعة مالية لكل عميل.

النظام يحل هذه التعقيدات عبر ربط أربع واجهات رئيسية:

  1. لوحة تحكم مركزية — للإدارة والمحاسبة
  2. تطبيقات موبايل — للمندوبين والمشرفين الميدانيين
  3. بوابة العميل — لمتابعة الشحنات وإدارة الحساب
  4. تطبيق سطح مكتب — لإرسال الفواتير الإلكترونية لمصلحة الضرائب

4. مكونات النظام

4.1 لوحة التحكم الإدارية

أ) إدارة العمليات واللوجستيات

  • لوحة معلومات — مؤشرات الأداء والرسوم البيانية
  • الحجوزات — صادر / وارد / تخليص جمركي، حاويات متعددة، خدمات، مستندات، بوليصات تسليم
  • الحاويات، الساحات، وكلاء الشحن، المدن والمناطق
  • لوحة توزيع المندوبين

ب) إدارة العملاء

  • الشركات — الرقم الضريبي، نوع الفوترة، الرصيد الافتتاحي، ترقيم الفواتير
  • الشركات الخاصة — بيانات الكيان القانوني للفاتورة
  • موظفو الشركات، المصانع والفروع

ج) الأسطول

  • السيارات (مع محفظة مالية)، السائقون، رحلات السيارات، مدفوعات السيارات

د) فريق العمل الميداني

  • المشرفون والمندوبون — محافظ، عهدة مالية، تحويلات، تقارير ومصاريف

هـ) الخدمات والتسعير

  • فئات الخدمات، كتalog الخدمات، أسعار النقل والخدمات لكل شركة (Excel)

و) المالية والمحاسبة

  • البنوك، الخزنة، الفواتير (PDF + ETA)، مدفوعات الفواتير
  • كشف حساب الشركة، إيصالات الدفع، إدارة الشيكات
  • كشف حساب السيارات، المركز المالي، الأرباح والخسائر

ز) إدارة المحتوى والنظام

  • صفحات، خدمات، آراء، رعاة، إعدادات، اتصل بنا
  • الصلاحيات، المستخدمون، اختبار الإشعارات

4.3 تطبيق المشرف الميداني

  • لوحة رئيسية، إدارة الحاويات والمندوبين
  • اعتماد المصاريف، تغيير حالة الحاويات
  • مهام وكلاء الشحن، شحن محافظ المندوبين
  • إشعارات المشرف + إشعارات كل المندوبين

4.4 بوابة العميل

  • تسجيل دخول للشركة وموظفيها
  • متابعة عامة بدون تسجيل — إدخال رقم الحجز
  • عرض الحجوزات، إدارة الموظفين، تحديث بيانات الشركة
  • بريد إلكتروني تلقائي مع رابط تتبع عند إنشاء حجز أو تغيير حالة

4.5 تطبيق سطح المكتب للفوترة

  • عرض الطلبات، بناء فواتير، إرسال جماعي لمصلحة الضرائب (ETA)

5. دورة حياة الحجز

1. الإدارة تنشئ الحجز → بريد للعميل مع رابط التتبع 2. المشرف يوزّع المندوبين على الحاويات 3. المندوب ينفّذ: تخصيص → تحميل → تعتيق → انتهى + مستندات + إشعارات 4. المندوب ينشئ بوليصة تسليم + مصاريف + تسوية 5. الإدارة تصدر الفاتورة → PDF + ETA 6. تسجيل المدفوعات → كشف حساب → تقارير مالية

6. النظام المالي

العهدة والمحافظ

عهدة مالية للمندوبين والمشرفين، محفظة لكل مندوب/مشرف/سيارة، تحويلات بين المندوبين، مصاريف متنوعة، تسوية بوليصة التسليم مع عمولة المكتب.

الفوترة

تجميع أسعار النقل والخدمات، حساب الضريبة والخصم، PDF، ربط مباشر بمصلحة الضرائب المصرية (ETA).

المحاسبة

كشف حساب الشركة، إيصالات دفع، إدارة الشيكات، تقارير المركز المالي والأرباح والخسائر، تصدير Excel.

9. ملخص القيمة للعميل

1
رقمنة كاملة لعمليات نقل الحاويات من الحجز حتى التحصيل
2
ربط المكتب بالميدان في الوقت الفعلي مع مستندات وإشعارات فورية
3
شفافية للعميل — تتبع الحجز عبر الإنترنت مع تنبيهات بريدية
4
امتثال ضريبي — فواتير إلكترونية متوافقة مع مصلحة الضرائب المصرية
5
محاسبة متكاملة — كشوف حساب، شيكات، خزنة، بنوك، أرباح وخسائر
6
تحكم مالي للميدان — عهدة، محافظ، مصاريف، وتسويات منظمة
7
تقارير ولوحة معلومات — قرارات مبنية على بيانات فورية
