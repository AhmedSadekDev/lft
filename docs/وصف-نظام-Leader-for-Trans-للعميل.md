## 1. نظرة عامة

**Leader for Trans** (نظام ليدر) هو منصة متكاملة لإدارة عمليات **نقل وتحريك الحاويات** وخدمات **الشحن البري واللوجستيات**، مصممة خصيصاً لشركات النقل في **السوق المصري**.

يربط النظام بين **المكتب الإداري**، **فريق العمل الميداني**، و**العملاء (الشركات)** في منصة واحدة تغطي دورة العمل الكاملة من **تسجيل الحجز** حتى **الفوترة الضريبية** و**تحصيل المدفوعات** و**التقارير المالية**.

| البند | التفاصيل |
|-------|----------|
| اللغة الأساسية | العربية (مع دعم الإنجليزية) |
| العملة | الجنيه المصري (ج.م) |
| التوقيت | توقيت القاهرة (Africa/Cairo) |
| السوق المستهدف | مصر — مع تكامل الفواتير الإلكترونية مع مصلحة الضرائب |

---

## 2. فكرة التطبيق والمشكلة التي يحلها

شركات نقل الحاويات تعتمد على عمليات متعددة ومتداخلة:

- حجوزات من عملاء مختلفين
- حاويات متعددة لكل حجز
- مندوبين ميدانيين ومشرفين
- سيارات وسائقين
- مصاريف يومية وعهدة مالية
- فواتير ضريبية ومتابعة مالية لكل عميل

**النظام يحل هذه التعقيدات** عبر ربط أربع واجهات رئيسية:

1. **لوحة تحكم مركزية** — للإدارة والمحاسبة
2. **تطبيقات موبايل** — للمندوبين والمشرفين الميدانيين
3. **بوابة العميل** — لمتابعة الشحنات وإدارة الحساب
4. **تطبيق سطح مكتب** — لإرسال الفواتير الإلكترونية لمصلحة الضرائب

---

## 3. المستخدمون وأدوارهم

| الدور | القناة | الوظيفة |
|-------|--------|---------|
| **موظفو الإدارة** | لوحة تحكم ويب | إدارة كاملة للعمليات، المالية، التقارير، والفواتير |
| **الشركة (العميل)** | تطبيق / بوابة العميل | متابعة حجوزاتها، تحديث بياناتها، إدارة موظفيها |
| **موظف الشركة** | تطبيق / بوابة العميل | يرى الحجوزات المخصصة له فقط |
| **المشرف الميداني (Super Agent)** | تطبيق موبايل | إشراف على المندوبين، توزيع المهام، اعتماد المصاريف |
| **المندوب الميداني (Agent)** | تطبيق موبايل | تنفيذ العمليات الميدانية، رفع المستندات، تسجيل المصاريف |
| **محاسب الفواتير** | تطبيق سطح مكتب | تجميع وإرسال الفواتير الإلكترونية للضرائب |

## 4. مكونات النظام

### 4.1 لوحة التحكم الإدارية (Back Office)

واجهة ويب شاملة للموظفين الداخليين.

#### أ) إدارة العمليات واللوجستيات

- **لوحة معلومات (Dashboard)**  
  مؤشرات الأداء: عدد الحجوزات، الحاويات، المندوبين، الشركات، السيارات، رصيد الخزنة، الإيرادات والمصروفات اليومية والشهرية، بوليصات التسليم، الفواتير، الشيكات المستحقة — مع رسوم بيانية للأشهر الستة الأخيرة.

- **الحجوزات (Bookings)** — نواة النظام:
  - أنواع الحجز: **صادر (Outbound)** — **وارد (Inbound)** — **تخليص جمركي (Clearance)**
  - ربط الحجز بالشركة، المصنع، الفرع، الساحة، وكيل الشحن، وموظف الشركة
  - **حاويات متعددة** لكل حجز (رقم الحاوية، السعر، المدن، الفروع، تاريخ الوصول)
  - **خدمات إضافية** (خاضعة للضريبة / غير خاضعة / غير مفوترة)
  - **مستندات الحجز** (أوراق لكل مرحلة)
  - **ملاحظات** على الحاويات
  - **بوليصات التسليم (Delivery Policies)** لكل حاوية
  - **تكاليف إضافية** على الحاويات

- **الحاويات** — بيانات أنواع وأحجام الحاويات
- **الساحات (Yards)** — مواقع تخزين ومعالجة الحاويات
- **وكلاء الشحن** — شركاء الشحن البحري
- **المدن والمناطق** — مرجع جغرافي للمسارات
- **لوحة توزيع المندوبين** — ربط المندوبين بالحاويات

#### ب) إدارة العملاء

- **الشركات (Companies)** — حسابات العملاء مع: الرقم الضريبي، نوع الفوترة (خاضع/غير خاضع)، الرصيد الافتتاحي، نوع الفاتورة، ترقيم تلقائي للفواتير، محفظة مالية
- **الشركات الخاصة (Private Companies)** — بيانات الكيان القانوني للفاتورة (الشعار، السجل التجاري، بيانات الاتصال)
- **موظفو الشركات** — حسابات فرعية تحت كل شركة
- **المصانع والفروع** — مواقع الاستلام والتسليم

#### ج) الأسطول والموردون

- **السيارات** — أسطول النقل مع محفظة مالية لكل سيارة
- **السائقون** — سجل السائقين
- **رحلات السيارات (Shipments)**
- **مدفوعات السيارات** — مرتبطة ببوليصات التسليم

#### د) فريق العمل الميداني

- **المشرفون (Super Agents)** — مع محفظة مالية ومعاملات وعهدة
- **المندوبون (Agents)** — مع محفظة، مصاريف، تحويلات، وتقارير
- **العهدة المالية (Financial Custody)** — صرف وتحويل وتسوية النقد اليومي للمندوبين والمشرفين
- **تحويلات بين المندوبين**
- **تقارير ومصاريف المندوبين**

#### هـ) الخدمات والتسعير

- **فئات الخدمات** — تصنيف: خاضع للضريبة / غير خاضع / غير مفوتر
- **كتalog الخدمات** — مع إمكانية الاستيراد من Excel
- **أسعار النقل لكل شركة** — استيراد/تصدير Excel
- **أسعار الخدمات لكل شركة**

#### و) المالية والمحاسبة

- **البنوك** — حسابات بنكية وحركات (إيداع/سحب)
- **الخزنة (Vault)** — الخزنة المركزية وحركاتها
- **الفواتير** — إنشاء، PDF، تصدير، إرسال/إلغاء/رفض عبر **مصلحة الضرائب المصرية (ETA)**
- **مدفوعات الفواتير** — نقدي، شيك (مع تاريخ استحقاق)، تحويل بنكي
- **كشف حساب الشركة** — Excel / PDF
- **إيصالات الدفع** — طباعة / PDF
- **إدارة الشيكات** — متابعة وتحديد كمدفوعة
- **كشف حساب السيارات**
- **المركز المالي للشركات** — الشركات ذات المديونيات
- **المركز المالي للسيارات**
- **تقرير الأرباح والخسائر**
- **تقرير المصروفات العام**

#### ز) إدارة المحتوى (CMS)

- صفحات ثابتة، خدماتنا، لماذا نحن، الرعاة، آراء العملاء
- إعدادات الموقع (هاتف، بريد، واتساب، روابط التواصل، الشعار)
- رسائل "اتصل بنا"

#### ح) إدارة النظام

- **الصلاحيات** — نظام صلاحيات تفصيلي (عرض / إضافة / تعديل / حذف) لكل وحدة
- **المستخدمون** — إدارة موظفي اللوحة
- **اختبار الإشعارات** — إرسال Push Notification يدوياً

### 4.2 تطبيق المندوب الميداني (Agent Mobile App)

تطبيق موبايل للمندوبين في الميدان:

| المجال | الوظائف |
|--------|---------|
| **الحساب** | تسجيل دخول، تعيين كلمة مرور، استعادة عبر OTP (بريد إلكتروني) |
| **الملف الشخصي** | عرض/تحديث البيانات، تغيير الصورة وكلمة المرور |
| **المحفظة** | عرض الرصيد، شحن محافظ السيارات |
| **العهدة المالية** | رصيد العهدة، تسجيل/تعديل/حذف مصاريف عامة وحجز |
| **بوليصات التسليم** | إنشاء، تعديل، عرض، مصاريف، تسوية، حذف |
| **مصاريف السيارات** | تسجيل مصاريف مرتبطة بالسيارات |
| **عمليات الحجز** | إتمام: **تخصيص → تحميل → تعتيق**، وإرسال ملاحظات |
| **المهام اليومية** | مهام التحميل / التخصيص / التعتيق لليوم |
| **المستندات** | رفع أوراق الساحة، الحاوية، الإبحار، السيارة |
| **التحويلات** | تحويل أموال لمندوب آخر |
| **الإشعارات** | إشعارات داخل التطبيق + Push Notifications |
| **بيانات مرجعية** | المدن، الساحات، السائقين، السيارات، الحاويات |

---

### 4.3 تطبيق المشرف الميداني (Super Agent Mobile App)

تطبيق للمشرفين على الفريق الميداني:

- **لوحة رئيسية** — نظرة عامة على العمليات
- **إدارة الحاويات** — قوائم التخصيص / التحميل / التعتيق / كل المهمات
- **إدارة المندوبين** — عرض المندوبين، توزيعهم على الحاويات
- **اعتماد المصاريف** — الموافقة على مصاريف مراحل الحاويات
- **تغيير حالة الحاويات**
- **مهام وكلاء الشحن** — تخصيص/تحميل، حفظ أوراق الساحة والحاوية
- **شحن محافظ المندوبين**
- **إشعارات** — إشعاراته + إشعارات كل المندوبين
- **الساحات** — قائمة الساحات والحجوزات النشطة

### 4.4 بوابة العميل (Client Portal)

| الميزة | التفاصيل |
|--------|----------|
| **تسجيل الدخول** | للشركة وموظفيها |
| **متابعة عامة (بدون تسجيل)** | إدخال رقم الحجز → عرض الحاويات وحالتها والمستندات |
| **الحجوزات** | عرض حجوزات الشركة |
| **الموظفون** | إدارة موظفي الشركة |
| **الملف الشخصي** | تحديث بيانات الشركة |
| **المحتوى** | صفحات، خدمات، آراء، رعاة، إعدادات |
| **اتصل بنا** | إرسال رسالة |

> عند إنشاء حجز جديد أو تغيير حالة حاوية، يُرسل **بريد إلكتروني** للعميل مع **رابط تتبع** مباشر.

### 4.5 تطبيق سطح المكتب للفوترة (Desktop Invoicing App)

تطبيق داخلي (Windows) لموظفي المحاسبة:

- تسجيل دخول / خروج
- **عرض كل الطلبات** مع بحث وترقيم صفحات
- **بناء فاتورة** من طلبات محددة
- **إرسال جماعي** للفواتير إلى **مصلحة الضرائب المصرية (ETA)**
- **تحديث حالة الإرسال**
- **عرض الشركات** المربوطة بنظام الفوترة الإلكترونية

## 5. دورة حياة الحجز

```
┌─────────────────────────────────────────────────────────────────┐
│  1. الإدارة تنشئ الحجز                                           │
│     → شركة + مصنع + فرع + ساحة + وكيل شحن + حاويات + خدمات     │
│     → إرسال بريد للعميل مع رابط التتبع                          │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  2. المشرف يوزّع المندوبين على الحاويات                         │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  3. المندوب ينفّذ المراحل عبر الموبايل:                         │
│     تخصيص → تحميل → تعتيق → انتهى                               │
│     + رفع صور/مستندات لكل مرحلة                                │
│     + Push Notification للمشرف/المندوب                          │
│     + بريد للعميل عند تغيير الحالة                              │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  4. المندوب ينشئ بوليصة تسليم (سيارة + سائق + حاويات)           │
│     + يسجّل المصاريف من العهدة/المحفظة                          │
│     + يُسوّي البوليصة ويُسجّل عمولة المكتب                       │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  5. الإدارة تصدر الفاتورة                                        │
│     → نقل + خدمات + ضريبة + خصم                                 │
│     → PDF + إرسال لـ ETA (اختياري)                              │
└──────────────────────────┬──────────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  6. تسجيل المدفوعات (نقدي/شيك/بنك) → كشف حساب → تقارير مالية   │
└─────────────────────────────────────────────────────────────────┘
```

### مراحل الحاوية التشغيلية

| المرحلة | الوصف |
|---------|--------|
| **تخصيص (Specification)** | تخصيص الحاوية في الساحة وأوراق التخصيص |
| **تحميل (Loading)** | تحميل الحاوية من المصنع / الفرع |
| **تعتيق (Unloading)** | تفريغ الحاوية في الوجهة |
| **انتهى (Finished)** | اكتمال العملية |

## 6. النظام المالي

### 6.1 العهدة والمحافظ

- **عهدة مالية** للمندوبين والمشرفين (صرف يومي من الإدارة)
- **محفظة** لكل مندوب، مشرف، وسيارة
- **تحويلات** بين المندوبين
- **مصاريف**: عامة، حجز، سيارة، بوليصة تسليم
- **تسوية بوليصة التسليم** مع تسجيل عمولة المكتب

### 6.2 الفوترة

- تجميع: **أسعار النقل (الحاويات)** + **خدمات خاضعة/غير خاضعة للضريبة**
- حساب **ضريبة القيمة المضافة** و**ضريبة المبيعات** والخصم
- ترقيم الفاتورة: `YYYY-XXX-###` (سنة — رقم الشركة — تسلسل)
- **PDF** للفاتورة
- **ربط مباشر بمصلحة الضرائب المصرية (ETA)** — إرسال، إلغاء، رفض، استخراج PDF ورابط المشاركة

### 6.3 المحاسبة

- **كشف حساب الشركة** = فواتير (مدين) + مدفوعات (دائن) + رصيد افتتاحي
- **إيصالات دفع** قابلة للطباعة
- **إدارة الشيكات** مع تواريخ الاستحقاق
- **تقرير المركز المالي** — الشركات والسيارات ذات المديونيات
- **تقرير الأرباح والخسائر**
- **تصدير Excel** للتقارير والبيانات

## 7. الإشعارات والتنبيهات

| القناة | الاستخدام |
|--------|-----------|
| **Push Notifications (Firebase FCM)** | تحويلات مالية، تغيير حالة الحاوية، تحويلات بين المندوبين |
| **البريد الإلكتروني** | حجز جديد، تحديث حالة الحاوية، تعيين كلمة مرور، OTP استعادة كلمة المرور |
| **إشعارات داخل التطبيق** | سجل إشعارات لكل مندوب / مشرف |

## 8. التكاملات الخارجية

| التكامل | الغرض |
|---------|--------|
| **مصلحة الضرائب المصرية (ETA)** | الفواتير الإلكترونية (إرسال / إلغاء / رفض) |
| **Firebase Cloud Messaging** | إشعارات الموبايل |
| **البريد الإلكتروني (SMTP)** | OTP، تنبيهات الحجز، تعيين كلمة المرور |
| **Excel** | استيراد / تصدير (شركات، أسعار، خدمات، تقارير) |
| **PDF** | فواتير، كشوف حساب، إيصالات |

> **ملاحظة:** المدفوعات تُسجّل يدوياً (نقدي / شيك / بنك) — لا يوجد ربط ببوابات دفع إلكترونية. OTP يُرسل عبر **البريد الإلكتروني** وليس SMS.

---

## 9. الأمان والصلاحيات

- **JWT** لجميع واجهات API (العملاء، المندوبين، المشرفين، سطح المكتب)
- **جلسات ويب** للوحة الإدارة
- **Spatie Permissions** — صلاحيات تفصيلية لكل وحدة في اللوحة (عرض / إضافة / تعديل / حذف)
- **أدوار منفصلة** — كل نوع مستخدم له قدرات محددة مسبقاً في API الخاص به

## 10. اللغات والتوطين

- **العربية** — اللغة الافتراضية
- **الإنجليزية** — مدعومة في الواجهات والـ API
- محتوى CMS (صفحات، خدمات، آراء، ساحات، مدن...) **قابل للترجمة**

## 11. ملخص القيمة للعميل

**Leader for Trans** يقدّم:

| # | القيمة |
|---|--------|
| 1 | **رقمنة كاملة** لعمليات نقل الحاويات من الحجز حتى التحصيل |
| 2 | **ربط المكتب بالميدان** — المشرف والمندوب يعملان في الوقت الفعلي مع رفع مستندات وإشعارات فورية |
| 3 | **شفافية للعميل** — تتبع الحجز والحاويات عبر الإنترنت مع تنبيهات بريدية |
| 4 | **امتثال ضريبي** — فواتير إلكترونية متوافقة مع **مصلحة الضرائب المصرية** |
| 5 | **محاسبة متكاملة** — كشوف حساب، شيكات، خزنة، بنوك، أرباح وخسائر |
| 6 | **تحكم مالي للميدان** — عهدة، محافظ، مصاريف، وتسويات منظمة |
| 7 | **تقارير ولوحة معلومات** — قرارات مبنية على بيانات فورية |
