# الرقم الداخلي العشوائي (`public_code`)

**Date:** 2026-10-22

## الهدف

رقم من 5 أرقام عشوائي (غير مسلسل) يظهر للعميل في واتساب/إيميل ورابط التتبع، وفي وسط رقم الفاتورة بدل رقم الشركة — حتى لا يُخمَّن الطلب التالي ولا يُفتح شغل زميل في نفس الشركة بتخمين الرقم.

## الشكل

| الاستخدام | القيمة |
|-----------|--------|
| تتبع العميل | `?track={public_code}` → `GET /api/booking/track?order_number={public_code}` |
| فاتورة جديدة | `YYYY-{public_code}-###` مثال `2026-48291-015` |
| مسلسل ### | عام على السنة حسب ترتيب إنشاء الفواتير (يشمل أرقام التنسيق القديم عند حساب الأعلى) |
| `booking_number` | يبقى مرجع تشغيلي/شحن في الداشبورد فقط |

## ملاحظات

- البحث العام لا يقبل `booking_number` بعد الآن — فقط 5 أرقام.
- الحجوزات القديمة تُعبَّأ من الـ SQL أو عبر `ensurePublicCode()` عند أول فاتورة/رابط.
